# 零售数据分析 SQL 作品集

## 📌 项目背景
本项目基于**完全虚构的零售模拟数据**，旨在展示使用 SQLite 进行业务数据查询、清洗、对比分析及数据洞察的能力。重点聚焦于门店横向对比、品类经营表现分类及商品机会识别。

## 💡 核心分析逻辑
1. **门店横向对比**：比较不同门店（如番禺店与竞对门店）的平均销售额、平均 PI 值（Purchase Index，购买指数，常称为「千人购买率」或「聚客指数」）差异。
2. **经营表现分类**：使用 `CASE WHEN` 设定 ±20% 阈值，将各品类划分为“明显较好、基本持平、明显较差”。
3. **商品机会识别**：在特定品类（如家庭装、杯装、雪条）中，找出其他门店表现优于目标门店的 Top 5 商品。

## 🛠️ 技术栈与工具
- **数据库**：SQLite
- **核心语法**：多条件筛选 (`WHERE`)、聚合汇总 (`GROUP BY`, `HAVING`)、条件判断 (`CASE WHEN`)、通用表表达式 (`CTE` / `WITH`)、排序与限制 (`ORDER BY`, `LIMIT`)

## 🤖 关于 AI 辅助的声明
本项目中的 SQL 代码在 **AI 工具的辅助下编写**。
本人主要职责：
- 明确业务分析口径（如 PI 值计算、对比维度）；
- 根据业务需求修改查询条件（切换门店、切换品类）；
- 验证查询结果的准确性与业务合理性。

## ⚠️ 数据安全声明
**本仓库不包含任何真实企业的业务数据。**
所有表结构、商品名称、门店信息及销售数值均为通过 SQL 脚本生成的**模拟数据**，仅用于演示 SQL 逻辑。

## 📁 目录结构
- `schema.sql`：建表语句（模拟数据结构）
- `seed_demo.sql`：生成模拟数据的 SQL 脚本
- `analysis.sql`：核心业务分析 SQL 脚本（原 Script-6）
- `results/`：查询结果截图或脱敏数据表
